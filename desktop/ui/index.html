使用同一套资产工作台。数据保存在您选择的目录，独立于 App。

连接数据目录

旧目录需要升级

先检查目录。升级前会创建 SQLite 备份；更高版本的数据库不能由本版直接打开。此处仅升级已知旧结构。

运行与通知

关闭活动任务窗口时可选择继续后台，或停止新增请求并等待收尾。CLI 启动的实例由原入口管理。

示例页面仅含合成资产，目标采集仍在独立 Chromium 中进行。

更新与恢复

只在您点击检查时访问配置的更新渠道。安装前验证官方更新包签名，并备份数据和此前程序。活动任务结束或明确停止后才可安装。

从已验证备份恢复数据

只恢复到新的空目录，不覆盖当前数据。备份之后的修改不会保留；恢复后周期计划保持暂停。程序回退不会自动回退数据。

请选择目录开始。正式分发签名、公证与更新渠道尚未发布。
