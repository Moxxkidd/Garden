## 性能归属与剩余限制

本版没有新增性能策略或无界规模实验。最终 App 3.204s 是本轮单次实测，不是多机保证。前版同机固定语料比较保持其原有归属：[v1.1](../versions/v1.1.0.md) 500 页 44.9855→24.7466s、TCP 连接 500→1；[v1.2](../versions/v1.2.0.md) 固定 50 请求预算的路由族 12→50；[v1.5](../versions/v1.5.0.md) 万条 JSON RSS 339.98→144.03MiB，但耗时 5.503→7.853s。这些没有在 v2 再测，不能写成 v2 新的提升。

macOS 候选只承诺 **Apple Silicon / macOS ≥26.0 本地 Beta**，实测 26.3。没有 Intel、Windows、更早 macOS 或外部干净机器/VM 证据。ad-hoc strict 验证不等于 Developer ID 签名、公证或 Gatekeeper 分发通过。正式签名、公证/装订、更新签名密钥与渠道、Garden 独立许可证及依赖再分发确认仍是独立发行事项；没有使用发布凭据、创建 tag/Release、上传包或改动日用数据库/服务。所有目标、账号和身份材料均为合成 fixture，不能外推为真实站点兼容保证。
