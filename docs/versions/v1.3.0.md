# v1.3.0 · 资产工作台与 WebUI

状态：CI 验证完成，已直接交付 main，未发布。对应 G2-10—12。前置：[v1.2.0](v1.2.0.md)。遵守[开发约定](development-rules.md)。

## 1. 目标与范围

让用户在数千条资产中找到核心页面/API、查看来源并形成可重复使用的人工清单。沿用 Jinja/HTMX，完成项目导航、模板视图与复核三个用户目标。不更换前端框架，不实现无限滚动、通用报表编辑器或机器自动“有效资产评分”。

## 2. 分片实施

### A · G2-10 项目工作台

- 导航统一为项目、任务、资产、身份、报告、设置，页面语言为中文。保持旧 URL 可访问，导航入口使用现有视图或薄聚合页。
- 新任务按入口/项目、采集模式/身份、范围/预算确认组织。默认预设沿用 v1.2.0，高级参数折叠，不添加第二次同义确认。
- 项目主页显示最近任务、资产分类、身份状态、缺口和待复核变化；计数来自现有项目投影，不加载全部资产后在模板计算。
- 将外部 CDN 改为包内固定资源。构建时生成 CSS、固定 JS 版本，运行时离线可用；不要同时维护 CDN 和本地两条加载链。

### B · G2-11 清单与路径模板

- 提供核心页面/API、全部资产、候选、人工保留、已忽略视图；复用既有分类，静态资源不删除。
- 模板组使用 v1.2.0 的路径族规则；按 origin、方法、路径模板和参数名分组。只聚合展示，不改资产 ID、请求变体或人工归并历史。
- 组内显示实例数、状态码、最近观察和身份差异；展开后访问现有实例详情。日期/数字以外的猜测不进入首版。
- 默认 50 条/页，支持排序、固定表头、列选择、保存筛选和批量选择。列选择可保存在本地浏览器；保存视图是项目级的名称与查询参数。
- 来源摘要保留数量，详细内容进入现有弹窗/详情；键盘可操作，窄屏只允许表格容器内滚动。

### C · G2-12 人工复核

- 新增 review_state=unreviewed/keep/ignore、理由、时间及操作历史，复用项目修订与审计/撤销模式。默认未复核，不从旧标签猜测正式状态。
- 支持对选定资产 ID 批量修改；本版不做“隐藏的全部筛选结果一键修改”。操作时显示选中数量。
- 再扫描保留人工状态；现有比较发现与该资产有关的观察属性变化时，额外标为需复核，不抹掉之前的选择。
- 扫描事实、被动迹象和人工选择分列显示；keep 只表示用户希望保留，不等于机器证明业务有效。

## 3. 接口与数据

复用[项目查询](../../app/services/project_catalog.py)、[人工整理](../../app/services/project_curation.py)、[项目页面](../../app/api/routes/project_pages.py)。只添加复核字段/记录和保存视图所需结构，不新建第二份资产事实表。

现有资产响应不改形状；模板使用独立投影，复核作为可选展示信息。保存视图只存已支持的查询字段，不保存 SQL 或表达式。新迁移按实际 head 生成；原始观察和旧报告保持不变。
