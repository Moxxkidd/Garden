# v1.7.0 · macOS App Beta

状态：本地 Beta 验收完成；最终候选全量由已授权 main CI 承担，结果待追加。未正式发布。对应 G2-22—24。前置：[v1.6.0](v1.6.0.md)；早期可行性实验如已单独执行，应核对后复用。遵守[开发约定](development-rules.md)。

## 1. 目标与范围

用 Tauri 2 + 冻结 Python sidecar + 共享 WebUI 提供可安装的 macOS Apple Silicon Beta。目标采集继续使用独立 Playwright Chromium。Python 3.12 仅为桌面捆绑运行环境，不改变核心包的 Python 支持承诺。

不同时开发 Windows、Intel Mac、移动端或第二套原生界面，不把扫描逻辑改写为 Rust。首版不安装系统启动项。

## 2. 分片实施

### A · 最小打包验证与 G2-22 运行握手

- 用现有一页 WebUI、PyInstaller 冻结的引擎和 Tauri 窗口验证启动、Chromium、下载、退出与 arm64 包资源；复用已经完成的提前实验。
- 添加引擎握手：应用标识、版本、数据目录和实例身份。未知进程占端口或版本不匹配时显示处理提示，不凭 healthz=200 接管进程。
- 同数据目录只有一个活动引擎，CLI、Web、App 复用实例和现有执行器锁。已有外部实例不因 App 退出被杀死；App 自建实例按其生命周期管理。
- 本地控制使用随机实例会话、Origin 校验和限定监听；外壳原生能力仅暴露给 Garden 页面。目标链接交给系统浏览器，采集页面留在独立 Chromium。

### B · G2-23 安装和交互

- 输出 .app/.dmg，包内含固定 Python、应用资源、迁移和匹配 Chromium；构建清单记录版本与架构，不依赖用户 PATH 或全局 site-packages。
- 第一启动提供新建数据目录或接入已有目录、代理检查和本地示例。旧目录需升级时显示具体步骤并备份，必须得到该操作授权后执行。
- 保留一套 WebUI，外壳只负责菜单、文件选择、通知和运行管理。菜单提供新建扫描、项目、导出、设置和诊断。
- 关闭窗口时若有活动任务，提供继续后台运行或停止新增请求后退出。停止后保存已完成观察，不改写中断状态。
- 默认不自动打开通知权限、不执行外部更新检查；用户启用对应功能后才使用。

### C · G2-24 更新与回退

- 使用 Tauri 官方 updater，实现用户触发检查与确认安装；验证更新包签名，不另造更新协议。
- 活动任务完成或明确暂停后才能替换引擎；更新前备份，启动失败能回到此前程序。
- 数据库不能仅因程序降级而直接打开新结构。需要恢复数据时选择已验证备份，明确说明备份后修改不会保留。
- 记录正式分发需要的签名、公证和许可证清单。只有具备凭据且本次获授权时才签名/公证；缺少这些材料可完成本地 Beta，但正式分发仍待验证，不能伪称已发布。
