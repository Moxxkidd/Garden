# v2.1.0 · Windows x64 安装包

基线为远端 main 的 `84f4e266c515baf864b166e9aae8b2aff30bd716`，前置桌面实现见 [v2.0.0](v2.0.0.md)。本版复用 Tauri 桌面壳及同一 Python 引擎，SQLite 迁移 head 保持 0016。

| 验收项 | 验证入口 |
| --- | --- |
| Windows 原生 x64 构建产出用户级 NSIS EXE，包含冻结引擎、Chromium、WebView2 离线安装器及第三方通知 | Windows CI 构建日志、体积和 SHA256、实际安装目录检查 |
| 安装后使用含中文及空格的路径，真实打开设置，初次建库并进入工作台；包内 Chromium 可离线渲染和下载 | `desktop/verify_windows.py` 使用 Windows 安装后的程序与 WebView2 |
| 关闭 App 后所拥有的引擎退出；重装和卸载保留独立数据目录，数据库完整 | 同一 Windows CI 安装旅程 |
| Linux 既有 CLI、Web、数据库和容器回归通过 | CI Python 3.10 / 3.12、CLI smoke 和 Docker 启动 |

Windows 项目数据保存在用户选择的本地 NTFS 目录，按目录继承的 ACL 管理权限。安装包操作和本地构建见 [桌面说明](../../desktop/README.md#windows-x64-安装包)。Windows 10 / 11 外部机器、普通用户账户、无现成 WebView2 的离线机器和正式 Authenticode 签名需要独立验收。
