# Garden v0.2.0 可信报告版开发日志

日期：2026-08-23

## 用户体验兼容

- CLI、Web、HTTP API、报告章节、扫描边界和状态语义保持不变。
- 原始资产、证据和发现继续完整保存；不增加数据库迁移。

## 报告可信度

- 版本线索只接受查询参数、具名组件路径或显式正文标记等可信上下文。
- CSS 数值、SVG 坐标、日期和无关小数不再被展示为版本。
- 重复发现以问题类型聚合展示，同时保留原始观察数量和引用样本。
- 缺少来源信息的旧记录只展示能够从 URL 重新验证的版本线索。

## 安装与发布

- 包版本和应用默认版本统一为 0.2.0。
- 沿用主线已有的 Python 3.12 发现、旧公网策略迁移和仓库源码遮蔽防护。
- 安装器托管配置升级为版本 3，不再把软件包版本固定写入 `config.env`。
- 版本 2 的托管配置会在升级时移除陈旧版本值；未托管配置中的显式自定义值保持不变。

## 验证记录

- 新安装和旧托管配置升级路径均通过安装器自动化测试。
- 隔离目录中的正式安装与数据库升级成功，`garden` 和 `gardenctl` 均输出 `Garden 0.2.0`。
- 从普通目录和仓库目录运行正式 CLI 的结果一致，当前源码不会遮蔽已安装包。
- 已安装运行时的真实 TCP 端到端扫描完成，报告、Web 详情、资产与证据均通过校验。
