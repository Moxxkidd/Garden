# 单 URL 报告覆盖质量开发日志

日期：2026-08-17

## 目标

提升单 URL 被动扫描在真实站点上的覆盖率和报告可读性，同时保持同源、只读 GET、地址策略校验、请求超时与整体超时等既有安全边界。

## 本次变更

- 将默认 HTML 页面预算从 10 提升到 50。
- 新增独立静态资源预算 `max_resources`，默认 200；CLI 对应参数为 `--max-resources`。
- 发现队列改为页面优先，静态资源不再挤占 HTML 页面预算。
- 资产类型细分为 `page`、`stylesheet`、`script`、`image`、`document`。
- 覆盖预算耗尽仍保留为运行告警，但在报告中与实际请求失败分开展示。
- 覆盖告警记录候选 URL 总数、已请求数量、未覆盖数量、命中的具体限制、未覆盖类型统计与代表样本。
- 规范化历史 `frame-options` 响应头为 `x-frame-options`，并对重复的单值安全头去重。
- CSS、JavaScript、图片和文档不再输出大段正文预览，改为大小、SHA-256、版本线索与安全信号摘要。
- 报告新增“已观察到的安全控制”，用于展示 HSTS、X-Frame-Options 等正向证据。

## 默认边界

| 参数 | 默认值 | 允许范围 | 说明 |
|---|---:|---:|---|
| `max_pages` | 50 | 1–500 | HTML 页面请求预算，入口页面计入 |
| `max_resources` | 200 | 0–2000 | CSS、JavaScript、图片和文档请求预算 |
| `max_depth` | 2 | 0–5 | 同源发现深度 |
| `overall_timeout_seconds` | 90 秒 | 由现有设置约束 | 页面和资源共用的整体截止时间 |

预算提升不改变目标授权要求，也不绕过同源限制、DNS/重定向地址校验、响应体大小上限或整体超时。

## 验证范围

- 默认页面和资源预算。
- HTML 资源发现分类与响应头规范化。
- 页面优先顺序和独立预算。
- 覆盖告警结构与请求失败分区。
- 静态资源元数据摘要和正向安全控制。
- 正式 CLI 与兼容 CLI 参数传递。
- 全量测试、Ruff 与差异格式检查。
